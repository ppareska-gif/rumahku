Aturan Keamanan Firestore (Proyek: rumahku-362c4)

Jika status menampilkan Periksa Rules Firestore, pastikan Firestore Database sudah dibuat di Firebase Console dengan rules berikut: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /rumahku_families/{familyId} {
      allow read, write: if true;
    }
  }
}
