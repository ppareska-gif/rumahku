Kode Keluarga Aktif:
------

Bagikan Link WhatsApp di atas ke anggota keluarga. Ketika link dibuka di HP mereka, seluruh data rumah tangga langsung tersinkronisasi secara real-time!

Firestore Rules (Proyek: rumahku-362c4) 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /rumahku_families/{familyId} {
      allow read, write: if true;
    }
  }
}
